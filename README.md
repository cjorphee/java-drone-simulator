# Simulateur de Drones d'Intervention (Java / POO)

Projet académique réalisé dans le cadre du module de Programmation Orientée Objet (ESIGELEC).

## 🚀 Fonctionnalités
- **Gestion des Sauveteurs (`Rescuer`)** : Contrôle d'intégrité des données (âge de majorité, longueur du nom/prénom).
- **Gestion des Drones (`Drone`)** : Positionnement 3D, calcul de la distance à l'origine et crash automatique en cas d'altitude négative.
- **Système d'Alerte** : Détection de proximité et alerte anti-collision entre deux drones sous un certain seuil.
- **Recherche** : Moteur de recherche d'un sauveteur par nom dans une liste dynamique.

## 🛠️ Technologies utilisées
- Java (JDK 17+)
- Programmation Orientée Objet (Encapsulation, Mutateurs/Accesseurs, Surcharge)
- Eclipse IDE
